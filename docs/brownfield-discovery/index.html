brownfield-discovery

Investigate an unfamiliar codebase and write down what you found.

Paste-ready prompt
skobarx.github.io/demotools/brownfield-discovery/prompt.txt
Works in any assistant that can read the repository. No install.

The design decision that matters

It investigates before it reads the documentation. Phases one to four never open README.md, CLAUDE.md, AGENTS.md or docs/. Only after its own findings are written does it read them, and then it produces a verdict for every material claim: confirmed, stale, contradicted, missing, or an undocumented strength. Anything left unresolved goes back for another research pass.

Existing documentation tells you what the authors believed was true, usually some time ago. An independent read is worth more, and the gap between the two is often the most useful finding in the repository.

What it produces

A discovery/ folder split by topic, so you can open just the part you need or hand one file to someone else: summary, architecture, stack, git history, data, integrations, quality, observability, risks, the documentation delta, ranked open questions, and a drafted AGENTS.proposed.md.

Diagrams are ASCII and sized to be redrawn by hand in under two minutes: annotated folder structure, a tier diagram marking every dependency pointing the wrong way, a module graph marking cycles, and an integration map showing direction, transport and whether each boundary has a translation layer.

Install for Claude Code

git clone https://github.com/skobarx/demotools /tmp/dt
mkdir -p ~/.claude/skills
cp -r /tmp/dt/skills/brownfield-discovery ~/.claude/skills/

Then run /brownfield-discovery, or /brownfield-discovery fast when time is short.

Git forensics on its own

git-forensics.sh — read-only, runs standalone. Change hot spots by file and directory, commit volume by month, contributor cohorts and when each first appeared, ownership and bus factor, hotfix and revert clusters, release cadence, merge patterns, active and stale branches, dependency and framework shifts, dormant areas, largest files, debt markers.

./git-forensics.sh 12   # months of history, default 12
