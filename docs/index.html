skill

brownfield-discovery

Drops into a codebase you have never seen and writes a structured discovery/ folder: architecture and tiers, git forensics, data and migrations, integrations, quality, observability and risks — plus a draft agent context file and a ranked list of questions for the humans.

It investigates before it reads the documentation. The first four phases never open a README or a context file. Only once its own findings are written does it read the docs, and then it reports the difference: confirmed, stale, contradicted, missing, or an undocumented strength.
